# intent/

One file per piece of work, written before the spec: `<yyyy-mm-dd>-<slug>.md`.
Sections: Problem, Proposed outcome, Affected users and systems, Constraints,
Open questions, with Author / Status (draft → accepted | closed) / Source in the
header. The shared `sdlc-intent` skill drafts them; Keith's edit is the review.

Closed intents stay here. The spec that follows an accepted intent lives in
`project_docs/design/` (unversioned) and links back to the intent by path.
